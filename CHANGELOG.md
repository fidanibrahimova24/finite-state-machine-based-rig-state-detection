# Changelog

All notable changes to this project are documented here.

## 0.2.0rc1 — 2026-09-26

- Aligned the public project title and citation metadata with the thesis title.
- Promoted the final linked-dashboard layout to the packaged Stage-3 engine.
- Preserved short connection episodes and aligned connection windows, markers and `Con.` labels to the same interval timestamps.
- Increased line, axis, label and export readability while preventing title and downstream-section overlap.
- Added separate matched log-scale axes for classical Teale and hydraulic MSE.
- Removed field-specific bit and hole-section defaults from reusable execution.
- Required explicit bit-size metadata when a valid bit-diameter channel is unavailable.
- Added well-name and direct output-directory support to the classification CLI.
- Kept raw well data, generated dashboards and local environments out of release archives.

## 0.1.2 — 2026-08-07

- Initial research release candidate with Stage 1–3 engines, CLI, semantic validation and dashboard generation.
